Videojuego de texto interactivo de terror desarrollado en C# como aplicación de consola.

Despiertas sin memoria en una casa que huele a polvo y humedad.
Para salir, tendrás que recorrer sus habitaciones, recoger cajas y pistas, y descubrir quién eres… y qué le pasó a tu madre.

2 finales alternativos, un nudo base de narración.
